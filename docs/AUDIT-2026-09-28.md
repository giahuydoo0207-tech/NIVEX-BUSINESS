## 1. Kiến trúc

```
Flutter Mobile ──Bearer (mobile_sessions)──┐
                                           ├──> Spring Boot 3.4 (Java 21) ──> PostgreSQL 16 (Flyway V1–V16)
Business Web (Next 16) ──/api/devnet proxy ┘         X-Nova-Demo-Key (server-side)
```

- Một backend, một database cho cả hai app. Web không gọi backend trực tiếp: route `app/api/devnet/[...path]` gắn `X-Nova-Demo-Key` phía server và chỉ cho phép các path trong allowlist.
- Chế độ live của web = `NEXT_PUBLIC_PAYMENT_MODE=devnet`. Khi tắt, web chạy fixtures/localStorage (demo offline).
- Mobile dùng backend khi build có `--dart-define=NOVA_API_URL=...`; không có thì chạy fixtures.

## 3. Database map

- Danh tính: `mobile_accounts.contractor_id` = `talent_profiles.contractor_id` = `community_profiles.id`. Phiên: `mobile_sessions` (access, 15 phút), `mobile_refresh_tokens` (30 ngày, xoay vòng).
- Community: `community_posts`, `community_comments` (cây qua `parent_comment_id`), `community_post_reactions` / `community_comment_likes.reaction_type` (LIKE, LOVE, HAHA, TRUST, BUILD, INSIGHTFUL, DEAL, LAUNCH), `community_follows/blocks/hidden/saved`.
- Jobs: `jobs` (+V16: `skills`, `engagement`, `payment_type`, `duration`, `published_at`), `job_applications` (7 trạng thái), `application_status_events`.
- Chat: `message_threads` (một thread cho mỗi cặp organization–contractor; PENDING/ACCEPTED/DECLINED/BLOCKED), `thread_messages` (`delivered_at`, `seen_at`). Mobile và web dùng chung bảng.
- Flyway trên DB thật: V1–V13 đã apply, checksum khớp; V14–V16 pending. Đã test bản sao dữ liệu thật: migrate V14→V16 thành công, validate pass.

## 6. Blocker còn lại

1. **Build APK**: Windows cạn commit memory (RAM + pagefile). Gradle daemon không cấp phát nổi heap (`insufficient memory … G1 virtual space`), log `android/hs_err_pid18936.log` lúc 16:33 cho thấy cùng lỗi. Khoảng 12 JVM của extension Java trên VS Code đang chạy. Lỗi `Unable to establish loopback connection` không tái hiện được khi test Selector/Pipe của JDK với TEMP hiện tại.
2. DB thật chưa apply V14–V16 (backend sẽ tự migrate khi khởi động).
3. `organizationId` cố định (`00000000-…-0001`) trong mọi controller business và mobile; web chưa có đăng nhập doanh nghiệp thật (demo key dùng chung).
4. 12 widget test UI fail từ trước (overflow Home 320dp, v.v.).
5. Comment trên mobile chỉ có nút Thích (LIKE); backend và web hỗ trợ đủ loại reaction.

## 7. Việc tiếp theo

- Giải phóng bộ nhớ rồi build: đóng các cửa sổ VS Code thừa, hoặc tắt `java.import.gradle.enabled` trong workspace để VS Code không tự dựng Gradle daemon cho Android; tăng pagefile. Sau đó:
  `flutter build apk --release --dart-define=NOVA_API_URL=http://<IP-LAN>:8080 --dart-define=NOVA_API_ALLOW_LOCAL_HTTP=true`
  và chạy backend với `SERVER_ADDRESS=0.0.0.0` để điện thoại truy cập được.
- Khởi động backend một lần để apply V14–V16 lên DB thật.
- Thay organization cố định bằng phiên đăng nhập doanh nghiệp.
- Sửa overflow Home 320dp để test UI xanh lại.
